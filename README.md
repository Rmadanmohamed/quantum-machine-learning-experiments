# Quantum Machine Learning Experiments

## Overview
A set of quantum machine learning notebooks covering quantum kernels, QNN architecture, and quantum convolutional neural networks.

## Problem Statement
Quantum ML experiments need reproducible comparisons against classical baselines and clear circuit/model documentation.

## Features
- Quantum kernel training experiment
- QNN architecture notebook
- QCNN notebook
- Classical SVM comparison

## Tech Stack
- Python
- Qiskit
- Scikit-learn
- NumPy
- Matplotlib

## Dataset
- Synthetic or referenced quantum kernel datasets
- ../../data/dataset_graph7.csv

## Models / Algorithms
- Quantum Kernel
- SVC
- QNN
- QCNN
- PCA

## Results
The notebooks include accuracy and confusion-matrix evaluation. One quantum kernel notebook output shows accuracy test: 1.0; rerun before treating it as final.

## Project Structure
- notebooks/
  - qiskit-quantum-kernel-training.ipynb
  - quantum-convolutional-neural-networks.ipynb
  - quantum-kernel-optimization.ipynb
  - quantum-neural-network-architecture.ipynb

## How to Run
- `pip install -r requirements.txt`
- `jupyter notebook notebooks/quantum-kernel-optimization.ipynb`
